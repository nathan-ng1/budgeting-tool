Budgeting Tool

A guided install for turning credit card statement exports into a categorised, local budget database — plus a Dashboard to see where your money went.

Before you start: this is a private repository. Everything below only works once nathan-ng1 has added you as a collaborator on github.com/nathan-ng1/budgeting-tool — this isn't a public release, just a guided install for people personally invited to use it. If you haven't been invited yet, ask before downloading anything from its Releases page.

Choose your path

setup.bat asks one question up front — do you already hold an AI subscription (Claude Code or Codex CLI)? — and configures everything else around your answer.

Full pipeline

I have a Claude Code or Codex CLI subscription

Statement Exports get categorised automatically. You'll still be asked to resolve anything the model isn't confident about, right in the terminal.

  • Automated Statement Export processing
  • Recurring transactions expanded automatically
  • The Dashboard, same as the other path
Dashboard only

I don't have either subscription

You skip the Statement Export pipeline entirely — no AI setup, no extra installs beyond the core tools. You still get the Dashboard, and you add transactions by hand or via a transactions import.

  • View/edit transactions, Budget tab, Recurring Transactions Config
  • Add transactions manually via the Dashboard's Transactions tab
  • Got a subscription later? Re-run setup.bat and switch paths any time

(An OpenAI-compatible endpoint — e.g. a local Ollama install — is also supported by the underlying pipeline, but it's a manual, README-documented option rather than something setup.bat walks you through.)

Prerequisites

These are common to both paths — setup.bat checks for each and offers to install anything missing via winget, confirming before every install:

ToolWhy
WindowsThe Installation Pack and day-to-day scripts are all .bat files.
GitClones the repo, and pulls updates later via update.bat.
uv + Python 3.12+Runs the pipeline and the Dashboard server.
Node.js 20+Builds the Dashboard frontend — always built, on either path.
GitHub CLI (gh)This repo is private — gh, logged in, is how the clone and update checks authenticate.

On the AI path, setup.bat also installs whichever of Claude Code or Codex CLI you choose (via npm), and checks you're actually logged in before continuing — not just installed.

Installing

1

Download setup.bat

From the latest Release on this repo, save setup.bat anywhere — your Downloads folder is fine. It doesn't need Git or a clone to already exist; it bootstraps both.

2

Double-click it

It checks each prerequisite above, asking before installing anything, then clones the repo and hands off to per-person setup: the AI-path question, then your Transactions Inbox folder and database file location (both suggested with sensible defaults — press Enter to accept them, or type your own path).

3

Wait for the frontend build

The Dashboard frontend is built automatically at the end, on both paths — it's the headline feature of this tool, so it's never left as an optional extra step.

4

Open the Dashboard

Double-click open_dashboard.bat in the cloned folder. It starts the local server and opens the Dashboard in Chrome — nothing about your transaction data ever leaves your machine. For a tour of what's on each tab, see docs/dashboard-guide.html.

Staying up to date

open_dashboard.bat checks, at most once a day, whether a newer version has been released, and prints a one-line notice if so — it never applies anything on its own, and if you're offline or not logged into gh, it just says nothing rather than erroring. When you see the notice, run:

update.bat

It shows you what's changed since your installed version, asks you to confirm, then pulls the update and re-syncs dependencies. If you've made local edits it can't safely combine with the update, it tells you rather than discarding them.

Re-running setup.bat

setup.bat is safe to run again at any time — it detects what's already installed and configured and skips or offers to reconfigure it, rather than starting over. This is also how a Dashboard-only install adds the AI path later: run it again and answer differently to the subscription question. Your existing Transactions Inbox and database path are kept unless you choose to change them.

Full manual setup instructions, troubleshooting, and non-Windows notes live in this repo's README.md. This guide only covers the guided Windows install.
